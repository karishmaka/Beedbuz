# BeedBuzz 🐝

**BeedBuzz** is a comprehensive social media application built for Beed, Maharashtra. It connects all talukas and villages in Beed, enabling residents to share city updates, photos, videos, stories, and engage with their local community - just like Instagram but tailored for our city.

## 📱 Features

### Core Features
- ✅ User Authentication (Email/Password, Phone OTP)
- ✅ User Profiles with followers/following
- ✅ Photo & Video Posts with captions
- ✅ Stories (24-hour auto-delete)
- ✅ Reels/Short Videos
- ✅ Comments & Likes
- ✅ Direct Messaging (1-on-1 & Group Chats)
- ✅ Search & Discover
- ✅ Hashtags & Trending
- ✅ Notifications (Real-time)
- ✅ Location Tagging (Talukas & Villages in Beed)
- ✅ Follow/Unfollow System
- ✅ Business Profiles & Shops
- ✅ Live Streaming
- ✅ Events Calendar (Local events in Beed)

## 🏗️ Project Structure

```
BeedBuzz/
├── backend/                    # Node.js + Express API
├── web/                        # React Web Application
├── mobile/                     # React Native Mobile App
├── shared/                     # Shared types & utilities
├── database/                   # Database schemas & migrations
├── docs/                       # Documentation
└── docker-compose.yml          # Local development setup
```

## 🛠️ Tech Stack

**Backend:** Node.js + Express + TypeScript
**Web:** React 18 + TypeScript
**Mobile:** React Native + TypeScript
**Database:** PostgreSQL + Redis
**Real-time:** Socket.io
**Storage:** AWS S3
